# 🏥 Mira Clinic - نظام إدارة المواعيد

نظام حجز ومراقبة المواعيد المتقدم للعيادات والمراكز الطبية، مع واجهة مستخدم عصرية وسهلة الاستخدام.

## ✨ المميزات الرئيسية

- 📅 **حجز المواعيد الذكي** - نظام حجز متقدم مع منع التضارب بين المواعيد
- 👨‍⚕️ **إدارة الأطباء** - إضافة وإدارة ملفات الأطباء والتخصصات
- 👥 **إدارة المرضى** - قاعدة بيانات شاملة لمعلومات المرضى
- 📊 **لوحة تحكم تحليلية** - إحصائيات ورسوم بيانية للأداء
- 🔔 **إشعارات فورية** - تنبيهات عند حجز أو تأجيل المواعيد
- 🎨 **تصميم استجابي** - يعمل بسلاسة على جميع الأجهزة
- 📱 **واجهة ثنائية اللغة** - دعم العربية والإنجليزية
- 🔐 **أمان عالي** - حماية بيانات المرضى والعاملين

## 🚀 البدء السريع

### المتطلبات
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- اتصال بالإنترنت
- JavaScript مفعّل

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/SDAIAAcademy/mira-clinic.git

# الدخول إلى المجلد
cd mira-clinic

# فتح الملف في المتصفح
# يمكنك ببساطة فتح الملف HTML مباشرة
```

### الاستخدام

1. افتح الملف `من كلاودappointment-system (9).html` في متصفحك
2. سجل دخول باستخدام بيانات اعتمادك
3. ابدأ في إدارة المواعيد والمرضى
